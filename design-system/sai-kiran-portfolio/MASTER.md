# Sai Kiran — Creative Engineer Portfolio
## Master design brief

**Art direction:** Dark editorial × technical luxury × cinematic 3D.

**Positioning:** Creative Engineer combining Integration & Data Engineering Architecture, full-stack engineering and AI-powered product experiments.

### Visual language
- Ink / charcoal foundations, warm-white typography, restrained electric-lime signal accent.
- Editorial typography with deliberate line breaks and controlled reading measure.
- Technical contour lines, precision grids, subtle grain, material depth and controlled specular lighting.
- Generous negative space, precise spacing, hairline borders and intentional hover/focus states.
- One distinctive visual signature per chapter; avoid repeating card grids and decorative motion without purpose.

### Narrative
- Hero: immediately legible name, portrait/object composition, role and one primary action.
- About: editorial biography and verified proof points.
- On Systems / Off Systems: enterprise integration/data engineering contrasted with creative experiments.
- Selected Work: case studies covering problem, architecture, role, constraints and verified outcomes.
- Engineering Lab: interactive experiments and shader studies.
- Journey: concise, credible timeline.
- Contact: decisive, low-friction close.

### Implementation
Preserve the existing Next.js 16, React 19, TypeScript, Tailwind CSS 4, React Three Fiber, Drei, Three.js, GSAP and Lenis stack. Prefer existing dependencies. Respect semantic HTML, keyboard navigation, visible focus, reduced motion, responsive behavior and contrast. Test 375px, 768px, 1024px and 1440px; run production build and relevant tests before claiming completion.

Use Lando Norris / Paddock as inspiration for narrative, transitions and craft—not as a source for copied personal branding, logos, proprietary photography or exact assets.
