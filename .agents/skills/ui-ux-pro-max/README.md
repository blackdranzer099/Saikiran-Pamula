# UI UX Pro Max — Project Integration

This directory contains a project-level Codex skill guide tailored to the Sai Kiran portfolio.

The upstream UI UX Pro Max engine is maintained at:
https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

For the complete official searchable data, scripts and platform templates, run from the repository root:
```bash
npx ui-ux-pro-max-cli init --ai codex
```

The guide in SKILL.md records this portfolio's actual stack, design direction and repository safety rules. It is not a vendored copy of the upstream database or search engine. The upstream project is MIT licensed; retain its license notice when installing or redistributing its files.
